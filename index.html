Three rules we don't break

Nothing fails silently.

Every path that can break without an error gets something that watches it. An API that renames a field should page a human, not return zero.

A failed read is never a zero balance.

Users don't lose money because an indexer had a bad minute. Unknown is unknown, and the UI says so.

Keys stay with their owner.

We build so that we can't move your users' funds, and we document exactly what we could do if we wanted to.
